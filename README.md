# 🧠 DataBossX - Legal Document Dashboard

## ✅ Features
- Upload and analyze PDFs for legal clauses
- Show clause confidence and risk scores
- Visual analytics: pie chart, bar chart
- Export results as JSON and Excel
- Works in Streamlit, Colab, and locally

## 🚀 How to Run

### On Local Machine
```bash
pip install -r requirements.txt
streamlit run app.py
```

### On Google Colab (if needed)
Use %%writefile app.py in a Colab cell and run as a script.

---

## 📦 Files Included
- `app.py` – Streamlit dashboard app
- `requirements.txt` – Python package list
