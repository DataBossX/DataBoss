# Isolated-agent tournament protocol

1. Assign every agent a unique folder: `_AI_<MODEL>_<ROLE>__<YYYYMMDD>/`.
2. Give them the public links, Issue #94 defects, and the OS non-negotiables.
3. They write only inside that folder: `README.md`, work product, `RECEIPT.md`.
4. Parent implements production changes on the feature branch.
5. `python -m databossx tournament` scores folders.
6. Blocking failures: missing receipt, client-shaped identifiers, second control plane, fabrication.
7. Winner ideas may be ported by the parent after tests. Folders are never runtime.
