# Evidence Standards

Evidence statuses are: `VERIFIED`, `DIRECTLY_OBSERVED`, `EXTRACTED_UNVERIFIED`, `INFERRED`, `ASSUMED`, `ESTIMATED`, `CONFLICTED`, `MISSING`, `NOT_APPLICABLE`, and `REJECTED`. Only supported statuses appropriate to the operation may drive a calculation or release gate.

A useful citation identifies source file, immutable hash, page/row/cell locator, and relevant text or geometry. OCR confidence measures engine output, not legal truth. External or deterministic candidates receive no trusted support merely because they agree; provenance is rebuilt against the current run's evidence ledger.

Material conflicts, unreadable pages, changed hashes, missing instruments/exhibits, and facts without direct support remain open. Human review must compare the source image, not only OCR text. The public repository must never contain real client evidence, owner data, title chains, manifests, hashes, or release receipts.
