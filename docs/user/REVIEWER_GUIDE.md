# Reviewer Guide

Start with the run manifest and source inventory. Reconcile file counts to the authorized corpus and investigate duplicate groups, scan errors, unsupported formats, changed hashes, and missing exhibits/schedules.

For each material instrument field, open the cited source page and verify identity, parties, dates, legal description, operative interest language, reservations, and cross-references. Review all OCR failures/weak results, candidate disagreements, unsupported fields, quarantined rows, chain gaps, unrepresented sources, and lease/tract drafts.

Recompute WI/NRI/net acres from cited terms and confirm burden basis. Inspect workbook before/after inventories and external links. The current exporter does not populate approved client ranges.

Record disposition and approval in the controlled private system. `READY_FOR_EXAMINER` means technical gates are clear but approvals are incomplete. `SOURCE_LIMITED` is internal only. External delivery is permitted only at `APPROVED_FOR_DELIVERY`; this software does not itself grant legal approval.
