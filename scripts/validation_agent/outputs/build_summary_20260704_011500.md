# DataBossX Validation Agent — Build Summary (Hardening Round)

- Date: 2026-07-04
- Follows: `build_summary_20260704_005000.md` (initial build)
- Scope: correctness fixes, a functional (not just fail-safe) repair path,
  integration coverage of the full state machine, and a security hardening.

## Bugs fixed (real correctness defects)

1. **Formula strings mis-parsed as numbers** (`validators/util.py`). After a
   formula repair, a total cell holds `=SUM(C2:C11)`; `parse_decimal` mined the
   `2` out of `C2` and re-flagged the acreage override forever, so a repaired
   workbook could never certify. `parse_decimal`/`parse_fraction` now return
   `None` for any `=`-prefixed value. This also prevents mis-reading any
   formula-driven cell across every validator.
2. **Version filenames accumulated `_vNNN` suffixes** (`core/run_manager.py`):
   `clean_v000_v001_v002.xlsx`. The stem's existing `_vNNN` is now stripped
   before appending, yielding a clean `clean_v000 → v001 → v002` chain.
3. **Acreage-total repair was flagged repairable but never planned.** The gate
   emitted an R1C1 coordinate the planner/XML editor couldn't target, so it
   always fell through to escalation. The gate now emits A1 coordinates and the
   sheet, and `repair_planner` derives a safe `=SUM(first:last)` over the tract
   acreage range. The repair now actually applies and the workbook certifies.

## Security hardening

- **XXE / entity-expansion defense** (`repair/xml_editor.py`): all worksheet XML
  is now parsed with a locked-down `lxml` parser
  (`resolve_entities=False, no_network=True, load_dtd=False, huge_tree=False`).
  Workbook XML is untrusted input; this closes XXE, billion-laughs, and
  entity-driven SSRF. Proven by
  `test_safe_parser_does_not_resolve_external_entities`.

## Test coverage added

- New `tests/test_integration_loop.py` (5 tests) drives the whole orchestrator:
  - clean workbook certifies with **no** repair (and exports a certified copy);
  - acreage-total override is **repaired via SUM** then certifies (v000→v001);
  - formula-column defect is repaired then certifies;
  - missing sources **escalate**, never certify, no certified export;
  - a safe defect + missing sources: the unsafe escalation **halts** the repair
    path (no repair attempted) — enforcing "unsafe failures halt repair".
- New XXE unit test.
